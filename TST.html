技术说明 / 浏览器兼容性

兼容性：只要浏览器实现了 Web Bluetooth 即可使用 —— Android Chrome、桌面 Chrome / Edge、HarmonyOS 上的 Chrome 等。本页不做浏览器限制：连接是否可用由系统/浏览器自身决定，若不支持会直接提示错误而非被拦截。iOS / Safari 不支持 Web Bluetooth（需走原生 App）。

扫描：Web Bluetooth 没有后台扫描，点"连接"唤起系统选择器，只列出本设备。
